# API для расчёта скоринга и интересов клиентов

HTTP API с валидацией запросов, авторизацией и тестами.

## Назначение

API предоставляет два метода:

- `online_score` — расчёт скорингового балла на основе переданных данных клиента.
- `clients_interests` — получение интересов по списку `client_id`.

Реализовано:

- валидация полей через дескрипторы;
- базовая авторизация по токену;
- контекст запроса (логирование, метрики);
- юнит-тесты на `unittest`.

## Требования

- Python 3.13.9 (или любая версия 3.13+).
- Только стандартная библиотека: сторонние зависимости не требуются.

## Установка и запуск

### Запуск сервера

python api.py

### Запуск тестов

python -m unittest test.py -v
